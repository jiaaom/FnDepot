# UP6 / T6 Drivers

English | [简体中文](README.zh-CN.md)

fnOS apps for the UnifyDrive UP6 / ZSpace T6: drivers, control center and front panel.

Source: <https://github.com/jiaaom/up6-linux-drivers>

## Install order

1. **T6 Drivers** (`t6-drivers`)
2. **T6 Control Center** (`t6-control`)
3. **T6 Front Panel** (`t6-panel`)

To upgrade, uninstall first and choose **Keep** settings.
