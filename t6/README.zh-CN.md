# UP6 / T6 驱动

[English](README.md) | 简体中文

UnifyDrive UP6 / 极空间 T6 的 fnOS 应用：驱动、控制中心和前面板。

源码：<https://github.com/jiaaom/up6-linux-drivers>

## 安装顺序

1. **T6 驱动**（`t6-drivers`）
2. **T6 控制中心**（`t6-control`）
3. **T6 前面板**（`t6-panel`）

升级前请先卸载旧版本，并选择 **保留** 设置。
